# LinkedIn Post — Velocity Drive Internship Project

I am excited to share **Velocity Drive**, a responsive Car Rental Management System that I created as part of my internship project.

The project is built with React, TypeScript, Tailwind CSS, and Vite. I focused on creating a clean, modern rental experience where users can explore vehicles, search and filter the fleet, review car details, save favorites, compare vehicles, and submit a validated booking request.

Some of the features I implemented include responsive layouts for mobile and desktop, dark mode, vehicle-detail pages, local browser persistence, booking history, animations, and a demo admin view.

This project helped me practice frontend development, component-based design, form validation, responsive UI/UX, and real-world project structure.

Live demo: https://velodrive-rentals.me  
GitHub: https://github.com/anon-443/velocity-drive-rental
